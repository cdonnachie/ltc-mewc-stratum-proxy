# Which Merge Mining Mode Should I Choose?

## TL;DR Recommendations

- **🏆 Best for Meowcoin Community**: LTC + MEWC (recommended!)
- **💰 Best Overall Value**: LTC + DOGE (Dogecoin has excellent liquidity)
- **⚡ Easiest Setup**: LTC Only
- **🚀 Maximum Rewards**: LTC + DOGE + MEWC (requires most resources)
- **🎯 Most Efficient**: LTC + MEWC (faster sync, lower resources, supports MEWC)

## Detailed Comparison

### LTC Only

**Choose if:**

- ✅ You only want Litecoin
- ✅ You have limited disk space (< 20GB pruned, < 300GB full)
- ✅ You have limited RAM (2GB available)
- ✅ You want the simplest setup
- ✅ You don't want to manage multiple wallets

**Don't choose if:**

- ❌ You want to maximize earnings from same hashrate
- ❌ You're willing to add auxiliary chains for extra rewards

**Resources:**

- Disk: 10GB (pruned) or 200GB (full)
- RAM: 2GB
- CPU: Medium
- Setup Time: ~1 hour (after sync)

**Earnings:**

- Litecoin blocks only
- Same hashrate = same LTC rewards as any mode

---

### LTC + DOGE (⭐ RECOMMENDED)

**Choose if:**

- ✅ You want the best value for your hashrate
- ✅ Dogecoin has good liquidity and value
- ✅ You can handle 3-4GB RAM
- ✅ You have 20GB+ (pruned) or 280GB+ (full) disk space
- ✅ You want popular, established auxiliary chain

**Don't choose if:**

- ❌ You have very limited disk space
- ❌ You only have 2GB RAM available
- ❌ You don't want to manage two wallets

**Resources:**

- Disk: 20GB (pruned) or 280GB (full)
- RAM: 3-4GB
- CPU: High
- Setup Time: ~2 hours (after sync)

**Earnings:**

- Litecoin blocks (same as LTC only)
- PLUS Dogecoin blocks (additional income!)
- Dogecoin is widely accepted and liquid

**Why Dogecoin?**

- ✅ Large, established community
- ✅ Good exchange liquidity
- ✅ Well-supported by exchanges
- ✅ Reasonably low difficulty
- ✅ Good value proposition

---

### LTC + MEWC (⭐ RECOMMENDED FOR MEOWCOIN COMMUNITY)

**Choose if:**

- ✅ You're part of the Meowcoin community
- ✅ You want to support and secure the Meowcoin network
- ✅ You prefer efficient resource usage
- ✅ Faster blockchain sync than Dogecoin
- ✅ You want frequent block finds (lower difficulty)
- ✅ You value community-focused projects

**Don't choose if:**

- ❌ You only want maximum exchange liquidity
- ❌ You prefer only the largest coins

**Resources:**

- Disk: 12GB (pruned) or 205GB (full)
- RAM: 3GB
- CPU: High
- Setup Time: ~1.5 hours (after sync, faster than DOGE)

**Earnings:**

- Litecoin blocks (same as LTC only)
- PLUS Meowcoin blocks (additional income!)
- More frequent MEWC blocks due to lower difficulty

**Why Meowcoin?**

- ✅ **Perfect for Meowcoin community members**
- ✅ Smaller blockchain (faster sync, less disk space)
- ✅ Lower difficulty (MORE blocks found than DOGE)
- ✅ Support and secure the Meowcoin network
- ✅ Direct contribution to project growth
- ✅ Most resource-efficient auxiliary mining option

## FAQ

**Q: Can I change modes later?**
A: Yes! Just stop containers, update `.env`, restart with new profile.

**Q: Will adding auxiliary chains reduce my LTC earnings?**
A: No! LTC earnings stay the same. Auxiliary chains are BONUS rewards for the same work.

**Q: Which mode uses least electricity?**
A: All modes use the same GPU power. Node operations are minimal CPU/disk.

**Q: Can I run multiple modes on different machines?**
A: Yes! You can run LTC+DOGE on one machine, LTC+MEWC on another, etc.

**Q: What if I don't have enough disk space for full nodes?**
A: Enable pruning! Set `LTC_PRUNE=10000`, `DOGE_PRUNE=10000`, `MEWC_PRUNE=2000` in `.env`

**Q: Which mode is most profitable?**
A: LTC+DOGE typically best value/resource ratio. LTC+DOGE+MEWC maximizes rewards.

**Q: How do I know which mode is working?**
A: Check logs: `docker compose logs -f stratum-proxy` - you'll see block submissions for active chains.
